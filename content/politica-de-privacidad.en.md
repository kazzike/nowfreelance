**Last updated: October 03, 2025**

### 1. General Information

This website is primarily informative. The only data collection is done through Cloudflare Web Analytics to understand site traffic and improve the user experience.

### 2. Cloudflare Analytics

We use Cloudflare Web Analytics, a service that collects anonymous data about:
- Number of visitors and page views
- Country of origin of visits
- Type of device and browser used
- Most visited pages and time spent

**Cloudflare does not use tracking cookies or collect personally identifiable data.** Full IP addresses are not stored and data is aggregated anonymously.

### 3. Anonymous Browsing

In addition to the anonymous data mentioned above, you can browse this website privately. We do not use contact forms, newsletters, or any other means involving the collection of direct personal data.

### 4. Your Rights

Since we do not collect personally identifiable data, we do not maintain any user database over which to exercise rights of access, rectification or deletion. Anonymous analytics data cannot be associated with individual users.

### 5. Changes to this Policy

If in the future we implement any system that collects personal data, this policy would be updated and you would be properly informed.
